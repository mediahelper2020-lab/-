# 🌱 평생과정설계 도우미 (PPP 웹앱)

발달장애인 **평생과정설계(PPP) 지원사업**의 「평생과정설계 자기소개서(행복을 이루기 위한 “나”의 이야기)」와
「미래설계 실천계획서」를 웹에서 작성하고, **무료 AI(키 없이 바로 사용 / Google Gemini 무료 키)** 로 초안·다듬기를 돕는 웹앱입니다.

설치나 서버가 필요 없는 정적 웹앱입니다. `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 주요 기능

| 메뉴 | 내용 |
|---|---|
| ① 진행과정 | 준비 → 계획(지원회의) → 실천 → 평가(모니터링) 단계별 진행일·회의 메모 기록, **AI 회의 질문 추천** |
| ② 자기소개서 | 한글 원본 서식의 전체 항목(기본정보, 꿈과 행복, 자립생활 체크, 8대 영역: 교육·보건의료·문화여가·직업·결혼·주거·법적·소득재정) 입력, **쉬운 말로 다듬기** |
| ③ 실천계획서 | 꿈과 희망 / 중장기목표 / 중요하게 생각하는 것 / 필요한 것 / 성공경험 + 영역별 단기목표·실천계획. **자기소개서로 AI 초안 만들기**, 영역별 AI 제안, 우선순위 조정 |
| ④ 평가 | 활동평가(월/분기/반기) 기록, 연 1회 실천과정 평가, **AI 평가 초안** |
| 출력 | 인쇄/PDF, 한글·워드에서 열리는 `.doc` 파일 저장 |
| 데이터 관리 | 참여자별 저장, JSON 백업/불러오기 |

AI 키가 없어도 **[AI 없이 초안 채우기]** 로 자기소개서 응답을 계획서 칸에 자동으로 옮겨 담을 수 있습니다.

## 무료 AI 연결 방법

**설정 없이 바로 사용됩니다.** 기본값은 키가 필요 없는 무료 AI([Pollinations](https://pollinations.ai))입니다.
다만 이용자가 몰리면 잠시 제한될 수 있으므로, 교육처럼 여러 명이 동시에 쓸 때는 Gemini 무료 키를 권장합니다.

**Gemini 무료 키로 바꾸기 (권장, 더 안정적)**
1. 구글 계정으로 <https://aistudio.google.com/apikey> 접속
2. **Create API key** → 키 복사 (무료 등급, 카드 등록 불필요)
3. 앱 상단 **⚙ AI 설정** → 「Google Gemini 무료 키」 선택 → 붙여넣기 → [연결 테스트] → [저장]

키는 사용자 브라우저(localStorage)에만 저장되며, 이 저장소나 다른 서버에는 저장되지 않습니다.

## 개인정보 보호

- 모든 기록은 **사용하는 브라우저에만** 저장됩니다(서버 없음).
- AI 버튼을 누를 때만 내용이 AI 서버(Pollinations 또는 Google Gemini)로 전송되며, 이름·생년월일·연락처·주소·가족 인적사항(🔒 표시 항목)은 **전송에서 제외**됩니다.
- **무료 AI는 입력 내용이 서비스 개선에 활용될 수 있습니다.** 실명·주민번호·구체적 병력 등 민감정보는 서술형 칸에도 적지 말고, 기관 개인정보 지침을 따르세요.

## 인터넷에 올려서 링크로 쓰기 (GitHub Pages)

1. GitHub 저장소 → **Settings → Pages**
2. Source: `Deploy from a branch`, Branch: 이 브랜치(또는 main) / `/ (root)` 선택 → Save
3. 잠시 후 표시되는 주소(`https://<아이디>.github.io/<저장소>/`)를 교육생에게 공유

## 파일 구성

```
index.html      화면 뼈대
css/style.css   디자인
js/schema.js    자기소개서·계획서·진행과정 양식 정의 (항목 수정은 여기서)
js/ai.js        무료 AI(Pollinations/Gemini) 호출, 프롬프트, AI 없는 초안 생성
js/app.js       화면 구성, 저장, 출력
```

양식 항목을 바꾸고 싶으면 `js/schema.js`의 항목만 고치면 화면·출력·AI 요약에 모두 반영됩니다.

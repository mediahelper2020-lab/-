# 🌱 평생과정설계 기록관리 (PPP 웹앱)

클로드복지관 발달장애인 **평생과정설계(PPP) 지원사업**의 참여자 기록을 한곳에서 관리하는 웹앱입니다.
한글 원본 서식 3종(자기소개서 · 미래설계 실천계획서 · 행복한 미래 이야기)을 그대로 웹 입력 화면으로 옮겼고,
첫 화면 **대시보드**에서 참여자 진행상황과 통계(원형그래프 등)를 한눈에 볼 수 있습니다.

설치나 서버가 필요 없는 정적 웹앱입니다. `index.html`을 브라우저로 열면 바로 사용할 수 있습니다.

## 대상 사용자
- PPP 담당 사회복지사, 팀장(현황 확인)
- 당사자·보호자와 함께 화면을 보며 작성하는 상황을 고려해 쉬운 말과 글자 크기 조절을 제공합니다.

## 주요 기능

| 메뉴 | 내용 |
|---|---|
| 📊 대시보드 | 전체·진행중 참여자, 평균 진행률, 자기소개서 작성률, 목표 달성률, 이번 달 일정, 점검 필요 인원 / **원형그래프**: 현재 단계, 참여 상태, 성별, 장애유형, 연령대, 실천과정 평가 달성도 / 막대: 1순위 희망영역, 영역별 단기목표 수, 단계별 완료 인원 / 참여자별 진행 현황표 / 다가오는 일정 / 점검 필요 참여자 / 담당자·상태 필터 / 인쇄 |
| 👥 참여자 관리 | 등록(표시 이름·상태·시작일·담당자), 수정, 검색(이름·담당자·장애유형·메모), 상태·단계 필터, 삭제(이름 재입력 확인), 교육용 가상 예시 데이터 |
| 📅 일정 | 월간 달력, 일정 등록·수정·삭제(지원회의·상담·실천활동·평가 등), 진행과정 단계 진행일 자동 표시 |
| ① 진행과정 | 준비 → 계획(지원회의) → 실천 → 평가(모니터링) 14단계 진행일·완료·회의 메모, AI 회의 질문 추천 |
| ② 자기소개서 | 「행복을 이루기 위한 “나”의 이야기」 전체 항목(기본정보, 꿈과 행복, 자립생활 체크, 8대 영역) |
| ③ 실천계획서 | 꿈과 희망 / 중장기목표 / 중요하게 생각하는 것 / 필요한 것 / 성공경험 + 영역별 단기목표·실천계획·우선순위 |
| ④ 행복한 미래 이야기 | 연도별 「지난해 돌아보기 · 올해 달라진 정보 확인하기 · 올해 행복한 삶 실천하기」 |
| ⑤ 평가 | 활동평가(월/분기/반기) 기록, 연 1회 실천과정 평가(달성도), AI 평가 초안 |
| 출력 | 서식별 인쇄/PDF 저장, 한글·워드에서 열리는 `.doc` 저장, 대시보드 인쇄 |
| 데이터 관리 | JSON 백업 파일 저장/불러오기(검증·미리보기), 참여자 삭제, 마지막 백업일 안내 |
| 글자 크기 | 상단 [가− / 가 / 가+] (90~130%) |

## 실행 · 설치 · 배포
- **바로 쓰기**: 저장소를 내려받아 `index.html`을 크롬/엣지로 엽니다.
- **Vercel 배포**: Vercel에서 이 저장소를 Import → Framework Preset `Other` → Build Command 비움 → Output Directory `/` → Deploy. `vercel.json`의 보안 헤더가 함께 적용됩니다.
- **GitHub Pages**: Settings → Pages → Deploy from a branch → 이 브랜치 `/ (root)`.

## 사용 순서
1. [👥 참여자 관리]에서 참여자 등록(가명·이니셜 권장). 교육 때는 [🧪 가상 예시 데이터]로 연습
2. [② 자기소개서]를 당사자·가족과 함께 작성
3. 지원회의를 진행하며 [① 진행과정]에 날짜·메모 기록, [③ 실천계획서] 확정
4. [📅 일정]에 회의·활동 일정 등록
5. 실천 기간 중 [⑤ 평가]에 활동평가 기록, 연 1회 [④ 행복한 미래 이야기]와 실천과정 평가 작성
6. [📊 대시보드]에서 전체 현황 확인

## ⚠ 데이터 저장 및 백업 주의사항
- 현재 버전은 기록을 **사용하는 PC의 브라우저(localStorage)에만** 저장합니다. 서버 DB는 아직 연결되어 있지 않습니다(설계: `DATA_MODEL.md` 5장).
- 브라우저 저장은 **기기·브라우저별로 분리**되며, **자동 동기화·암호화·다중 사용자 권한 관리가 없습니다.**
- 브라우저의 "인터넷 사용 기록 삭제", 시크릿 창 종료 시 기록이 사라질 수 있습니다.
- [데이터 관리 → 전체 백업 파일 저장]을 정기적으로(권장: 주 1회) 실행하고, 백업 파일은 기관의 접근 통제된 저장소에 보관하세요. 백업 파일은 암호화되지 않은 개인정보 파일입니다.
- 공용 PC에서는 사용하지 마세요.

## 무료 AI (선택 기능)
기본값은 키가 필요 없는 무료 AI([Pollinations](https://pollinations.ai))이며, [⚙ AI 설정]에서 Google Gemini 무료 키로 바꿀 수 있습니다.
AI 버튼을 누를 때만 내용이 전송되고 🔒 개인정보 항목은 제외됩니다. 무료 AI는 입력 내용이 서비스 개선에 활용될 수 있으므로 서술형 칸에도 실명·민감정보를 적지 마세요.

# 🛡️ 웹앱 보안 자가진단 도구

바이브코딩(Vibe Coding)으로 만든 **내 웹앱**이 실수로 민감한 정보를 노출하고 있지 않은지 점검하는 **방어적 자가진단 도구**입니다. 사회복지사 대상 AI 교육 등에서, "내가 만든 앱이 안전한지" 쉽게 확인하는 용도로 쓸 수 있습니다.

## ✅ 무엇을 점검하나요

브라우저가 어차피 내려받는 **공개된** HTML / JavaScript 번들 / 응답 헤더만 읽어서(수동 분석) 다음을 점검합니다.

- **노출된 비밀키/시크릿**: AWS, Stripe, OpenAI, Anthropic, GitHub 토큰, 개인키, 하드코딩된 비밀번호 등
- **Supabase 설정**: anon 키 / service_role 키(치명적) 구분, 스키마가 익명 키로 열람되는지 → **RLS 점검 가이드**
- **보안 헤더**: CSP, HSTS, X-Content-Type-Options, X-Frame-Options, Referrer-Policy
- **CORS 설정**: 와일드카드(`*`) + 자격증명 허용 등 위험 조합
- **소스맵(.map) 공개 여부**
- **민감 경로 노출**: `/.env`, `/.git/config`, DB 백업 등
- **HTTPS 미적용 / 기술 스택 버전 노출**

각 항목은 **심각도(매우위험·위험·주의·참고·정보)** 와 함께 **쉬운 한국어 설명 + 조치방법**으로 안내합니다.

## 🚫 하지 않는 것 (안전장치)

- 타인 소유 사이트 무단 점검 — 사용 전 **본인 소유/권한 확인 체크** 필수
- 공격·익스플로잇·데이터 덤프·대량 요청 — 수행하지 않음
- 내부/사설 네트워크(localhost, 사설 IP, 클라우드 메타데이터) 대상 — 차단(SSRF 방지)
- 요청 레이트 리밋 적용

> 이 도구는 교육·자가진단 목적입니다. 결과는 참고용이며 완전한 보안을 보장하지 않습니다. 본인이 소유하거나 명시적 점검 권한이 있는 사이트에만 사용하세요.

## 🚀 실행 방법

```bash
npm install
npm start
# 브라우저에서 http://localhost:3000 접속
```

Node.js 18 이상이 필요합니다(내장 `fetch` 사용).

## 🏗️ 구조

```
server.js          # Express 서버 + 입력검증/SSRF 방지/레이트리밋
lib/scanner.js     # 점검 로직 (수동 분석)
public/index.html  # 한국어 UI
```

# 🌱 성민복지관 평생과정설계 (PPP 웹앱)

발달장애인 평생과정설계(PPP)의 **상담(자기소개서) → 지원계획(사전·통합·컨퍼런스·확정회의, 단기계획) → 실천 → 모니터링**을
한 화면에서 기록하는 웹앱입니다. 서버 없이 `index.html` 하나로 동작합니다.

## 새로 더한 것

### 🏡 아바타 마을 홈
- **＋ 대상자 등록**: 이름·기본정보를 넣고 피부색, 머리, 옷, 표정, 꾸미기를 골라 아바타를 만듭니다.
- 캐릭터는 지금 진행 단계의 장소에서 돌아다닙니다:
  마을 광장(시작 전) → 이야기집(상담) → 회의마루(지원계획) → 실천 놀이터(실천) → 전망대(모니터링)
- **캐릭터를 누르면** 진행 단계, 꿈과 희망, 중장기목표, 8개 영역 현황, 지원회의 이력, 의사소통 지원을 모두 보고,
  바로 이어서 작성하거나 새 지원회의를 시작할 수 있습니다.
- 팻말을 누르면 그 장소에 있는 사람만, 검색창에 이름을 넣으면 그 사람만 표시합니다.

### 🤖 AI 모델 여러 개 등록 (ChatGPT · Gemini · Claude)
- **AI 모델 설정**(홈, 사이드바, 상단 ⋯ 메뉴)에서 회사별 **본인 API 키**를 넣고, 쓰고 싶은 모델 버전을 여러 개 등록합니다.
- AI 버튼을 누를 때마다 **어떤 모델로 쓸지 고릅니다.** 결과가 마음에 안 들면 「다른 모델로 다시」로 비교합니다.
- AI 기능:
  - 상담: **AI 상담내용 분석** → 분석 결과 칸에 넣기
  - 지원계획 각 단계: **AI 계획서 초안** → 지금 내용과 나란히 비교 후 「빈 칸만 채우기」 또는 「모두 바꾸기」
  - 실천·모니터링: **AI 종합의견** 초안
  - 모든 글상자: 누르면 나오는 **✨ 다듬기**
  - 캐릭터 카드: **AI 진행 요약**

| 회사 | 키 발급 |
|---|---|
| ChatGPT (OpenAI) | https://platform.openai.com/api-keys |
| Gemini (Google) | https://aistudio.google.com/apikey |
| Claude (Anthropic) | https://console.anthropic.com/settings/keys |

모델 ID는 회사 사정에 따라 바뀝니다. 설정 화면의 **테스트**가 실패하면 각 회사 문서에서 정확한 모델 ID를 확인해 직접 입력하세요.

## 개인정보와 키 보호
- 기록과 API 키는 **사용하는 브라우저에만** 저장됩니다. 키는 「작성본 HTML 저장」·백업 파일에 **들어가지 않습니다.**
- AI에는 이름·생년월일·연락처·주소·작성자·함께하는 사람 정보를 보내지 않고, 글 속 이름은 「당사자」로 바꿔 보냅니다.
  자유서술 칸에 쓴 다른 개인정보는 그대로 전송되므로 기관 지침에 맞게 확인하세요.
- 공용 PC에서는 사용 후 AI 설정에서 키를 지우세요. 사용 요금은 각 회사 계정으로 청구됩니다.

## 파일 구성과 수정 방법

```
index.html            배포되는 앱 (원본 디자인 + 아래 두 파일을 합친 것)
src/village-ai.css    아바타 마을 · AI 화면 디자인
src/village-ai.js     아바타 마을 · 캐릭터 카드 · AI 모델 연결
build.py              src 파일을 index.html에 다시 넣는 스크립트
```

`src/` 파일을 고친 뒤 `python3 build.py`를 실행하면 `index.html`에 반영됩니다(여러 번 실행해도 안전).
